# 🧹 LarLimpo — Serviços de Limpeza Residencial

App web moderno e responsivo para serviços de limpeza residencial.

## ✨ Funcionalidades

- Página inicial com hero atrativo
- 6 tipos de serviços detalhados
- Planos de preço (Básico, Completo e Premium)
- Seção "Como funciona"
- Depoimentos de clientes
- Formulário de agendamento interativo
- Design 100% responsivo (mobile + desktop)
- Menu mobile

## 🚀 Como usar

1. Abra o arquivo `index.html` no navegador
2. Ou faça o deploy em qualquer hospedagem estática:
   - [Netlify](https://netlify.com)
   - [Vercel](https://vercel.com)
   - [GitHub Pages](https://pages.github.com)

## 🛠 Tecnologias

- HTML5
- Tailwind CSS (via CDN)
- Font Awesome
- JavaScript vanilla

## 📱 Preview

Abra o `index.html` localmente ou faça o deploy para ver o app funcionando.
